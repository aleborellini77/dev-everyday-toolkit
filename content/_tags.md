# Tag condivisi tra le categorie. Una riga per tag: - nome-tag: descrizione
# Si usano in coda alla riga di un tool:  - [Nome](https://url): descrizione #cli #brew
# Un tag non elencato qui fa fallire la build (così un refuso come #clii non crea un tag nuovo).

- cli: runs in the terminal
- brew: installable with Homebrew on macOS
- no-signup: usable without creating an account
- status: outage and status pages of third-party services
- network: ping, traceroute, ports, bandwidth
- ip: IP address lookups
- security: TLS, headers, scanning, reconnaissance
- performance: speed, Core Web Vitals, bundle weight
- lint: validators and linters
- playground: safe sandbox, never touches production
