- [Shopify Status](https://www.shopifystatus.com): Check whether an outage is Shopify's fault before touching the store. #no-signup #status
- [Shopify Community](https://community.shopify.com): Search merchant and dev threads for the exact error you're seeing.
- [Theme Check](https://shopify.dev/docs/storefronts/themes/tools/theme-check): Lint Liquid and JSON for errors before they hit production. #lint
- [Shopify Theme Inspector](https://github.com/Shopify/shopify-theme-inspector): Profile Liquid rendering in Chrome to find what's slowing a theme. #performance
- [Shopify CLI](https://shopify.dev/docs/api/shopify-cli): Scaffold, preview, and push theme or app changes from the terminal. #cli
- [Shopify Dev Docs](https://shopify.dev): Look up any Liquid object, Admin API endpoint, or webhook payload.
- [Partner Dashboard](https://partners.shopify.com): Manage dev stores, API credentials, and app/theme logs.
