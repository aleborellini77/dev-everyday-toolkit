- [MXToolbox](https://mxtoolbox.com): Run DNS, MX, and blacklist checks from one box.
- [DNS Checker](https://dnschecker.org): See DNS propagation across servers worldwide. #no-signup
- [WHOIS Lookup](https://whois.domaintools.com): Check domain registration, expiry, and ownership. #no-signup
- [Google Public DNS](https://dns.google): Query records directly, no local caching guesswork. #no-signup
- [DNSdumpster](https://dnsdumpster.com): Map every subdomain and host tied to a domain at once. #no-signup #security
- [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/): Run dig-style raw record queries from the browser. #no-signup
