- [MXToolbox](https://mxtoolbox.com): Run DNS, MX, and blacklist checks from one box.
- [DNS Checker](https://dnschecker.org): See DNS propagation across servers worldwide.
- [WHOIS Lookup](https://whois.domaintools.com): Check domain registration, expiry, and ownership.
- [Google Public DNS](https://dns.google): Query records directly, no local caching guesswork.
- [DNSdumpster](https://dnsdumpster.com): Map every subdomain and host tied to a domain at once.
- [Google Admin Toolbox Dig](https://toolbox.googleapps.com/apps/dig/): Run dig-style raw record queries from the browser.
